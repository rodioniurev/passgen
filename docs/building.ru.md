# Сборка из исходников

[← к README](../README.ru.md) · [English version](building.md)

PassGen собирается штатным компилятором из .NET Framework 4, который уже есть в Windows. Visual Studio, .NET SDK и любые другие инструменты **не нужны**.

## Требования

- Windows с .NET Framework 4.x (входит в Windows 10 и 11; в Windows 7 нужно поставить .NET Framework 4.x).
- Компилятор `csc.exe` из `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\` — он поддерживает **C# 5** (см. [ограничения языка](#ограничения-языка)).
- Для публикации на GitHub — `git`.

## Сборка

```bat
git clone https://github.com/rodioniurev/passgen.git
cd passgen
build.bat
```

Результат — `PassGen.exe` в корне репозитория (около 125 КБ).

Что делает `build.bat`:

1. Если `PassGen.exe` уже есть, закрывает работающую копию командой `PassGen.exe /exit` — иначе файл занят.
2. Компилирует все `src\*.cs` в `PassGen.new.exe`:
   - `/target:winexe` — оконное приложение без консоли;
   - `/optimize+` — оптимизация;
   - `/codepage:65001` — исходники в UTF-8;
   - `/win32icon` — значок файла в проводнике;
   - `/win32manifest:src\app.manifest` — манифест: чёткое отображение при масштабе экрана 125–200 % (`dpiAware`) и совместимость с Windows 7–11;
   - `/resource:src\passgen.ico,passgen.ico` — тот же значок как ресурс: из него рисуется значок в трее.
3. Подменяет `PassGen.exe` новым файлом. Запущенный или занятый антивирусом exe нельзя перезаписать, но можно переименовать, поэтому старый файл сначала переименовывается в `PassGen.old.exe`, а потом удаляется.

Если сборка падает с ошибкой «файл используется другим процессом», закройте PassGen (`PassGen.exe /exit` или «Выход» в меню значка) и повторите.

## Ограничения языка

Встроенный компилятор понимает только C# 5. Поэтому в коде **нельзя**:

- интерполяцию строк `$"…"`;
- оператор `?.`, члены-выражения `=>` у свойств и методов, `nameof`, инициализаторы автосвойств;
- объявление переменной прямо в `out` (`out var x`), кортежи, локальные функции, `using static`;
- сопоставление с образцом (`is Type x`), `throw`-выражения, фильтры исключений (`when`).

Это сознательный компромисс: взамен получаем один exe около 125 КБ, которому не нужны ни установка, ни SDK.

## Значок

Значок (`src\passgen.ico`) нарисован скриптом и лежит в репозитории готовым. Чтобы перерисовать:

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File tools\make-icon.ps1
```

Скрипт собирает `.ico` из кадров 16–256 пикселей: мелкие — в классическом формате DIB (их читает `System.Drawing.Icon` для трея), крупные — PNG.

## Тесты

Два скрипта запускаются на уже собранном exe, окон не открывают и клавиш не нажимают:

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File tests\GeneratorTests.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tests\LocalizationTests.ps1
```

- `GeneratorTests.ps1` — генератор паролей: наборы знаков, «Удобно вводить», блоки, минимумы, крайние случаи, подготовка текста буфера обмена.
- `LocalizationTests.ps1` — таблица переводов: нет пропущенных и пустых переводов, подстановки `{0}` совпадают, в исходниках нет опечаток в ключах, подсказка значка в трее укладывается в 63 знака, формы множественного числа, выбор языка.

Код возврата `0` — всё прошло, `1` — есть провалы. Интерфейс, перехват клавиш, ввод и фокус автотестами не покрыты — для них есть [ручной чек-лист](../CONTRIBUTING.md#ручная-проверка).

## Непрерывная сборка и релизы

Файл [`.github/workflows/build.yml`](../.github/workflows/build.yml) на каждый push и pull request собирает exe на `windows-latest`, запускает оба скрипта тестов и прикладывает `PassGen.exe` как артефакт.

Чтобы выпустить релиз:

1. Поднимите версию в `src/AssemblyInfo.cs` (две строки: `AssemblyVersion` и `AssemblyFileVersion`) и добавьте запись в [CHANGELOG.md](../CHANGELOG.md).
2. Закоммитьте и поставьте тег:

   ```bat
   git tag v1.3.0
   git push origin main --tags
   ```

3. Workflow по тегу `v*` соберёт exe и создаст релиз на GitHub: к нему приложатся `PassGen.exe` и `PassGen.exe.sha256` (контрольная сумма).

## Структура репозитория

```text
.github/            шаблоны issue и pull request, workflow сборки
docs/               документация и скриншоты (docs/img/<язык>/)
src/                исходники (C# 5), манифест и значок
tests/              автотесты (генератор, переводы)
tools/              вспомогательные скрипты (рисование значка)
build.bat           сборка
```
